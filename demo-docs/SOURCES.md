# Demo document sources

Every document in this folder is committed to a PUBLIC repository. This file
records the origin and usage rights of each one. Rule: if a document's origin
or licence is unclear, it does not belong here — put it in `/private-samples/`
(which is gitignored) instead.

## Real third-party document

- **`m3-sample-reserve-fund-study.pdf`** — a sample reserve fund study published
  by M3 Consulting (Alberta) on their own public website as a marketing sample:
  http://www.m3consulting.ca/images/Sample-study1.pdf (downloaded Oct 18, 2026).
  Used only to sanity-check the extraction pipeline against a genuine
  third-party document. All names, numbers, and contact details inside are the
  firm's own published sample content. If M3 Consulting ever asks for its
  removal, remove it.

## Synthetic documents (generated by us)

All other PDFs in this folder are **fictional**, generated by
`generate_demo_docs.py` (reportlab) on Oct 18, 2026, for the "North Hill
Terrace" demo building (Condominium Corporation No. 0614321 — a made-up
number). Every page is watermarked "SAMPLE DOCUMENT — DEMO DATA ONLY".
They contain six baked-in red flags (2026 set) used as acceptance tests for
the analysis prompt:

2026 set (`demo-01` … `demo-04`):
1. $8,500/unit special assessment, levied (parkade membrane)
2. Reserve fund at 61% of study recommendation
3. Unfunded $1.15M envelope remediation
4. Window water-ingress litigation in mediation (units 304, 305, 406)
5. $100,000 insurance deductible after a hail claim
6. Proposed 15% rental cap (22% currently rented) + repeat nuisance complaints (unit 1204)

2024 set (`demo-2024-01`, `demo-2024-02`): an older document set for the same
fictional building, with deliberately different numbers, used to demonstrate
the "what changed since the last review" memory diff (no special assessment
yet, $25,000 deductible, no litigation, 63% funded).

No real people, buildings, or personal data appear in any synthetic document.
